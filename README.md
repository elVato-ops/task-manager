# 💸 Task Manager API

## Overview
REST API for managing users, projects, and tasks.

## Features
- Create users and projects
- Assign users to tasks
- Validation & business rules
- Global error handling

## Tech stack
- Java 21
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Spring Security

## How to run
mvn spring-boot:run

## API docs
http://localhost:8080/swagger-ui.html
